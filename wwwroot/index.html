      How it works

      Turn the research-form export into a clean Excel file in three steps.

      1. UploadChoose or drag in the .xlsx file. Columns are renamed and Age, Is Sample Twin and the 2D:4D finger ratios are calculated for you.
      2. AdjustUse the buttons above the preview: Filter rows keeps only the rows you need, Choose columns picks, renames and orders columns, Sort rows sets the row order. The preview updates as you go.
      3. ExportName the file in the bar at the bottom and click Export workbook.
      What do the other words mean?
      Sheet
      A tab in the exported Excel file. You can add several, each with its own filters and columns.
      Setup
      All your sheets, filters and columns saved under a name, so next month's file can be exported the same way in one click.
      Saved filters
      Just the filter conditions of one sheet, saved under a name to reuse later.
      Clean-up rules
      Optional fixes for common data-entry issues. Off by default: values are exported exactly as uploaded.
      ALL / ANY
      With ALL, a row must match every condition. With ANY, matching one condition is enough.
